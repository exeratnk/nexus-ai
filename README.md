# NexusAI

NexusAI — веб-приложение для общения с AI в удобном и современном интерфейсе. Проект объединяет быстрый фронтенд на React и серверную часть на Django, обеспечивая авторизацию, хранение чатов, работу с профилем пользователя и поддержку персонального пространства для общения.

Главная идея NexusAI — сделать взаимодействие с AI не просто рабочим, а комфортным. В приложении предусмотрены отдельные чаты, сохранение истории, аннотации к сообщениям, фокус-режим для концентрации на диалоге и личный кабинет с редактированием профиля. Благодаря этому сервис подходит не только для разовых запросов, но и для более длительной, организованной работы с диалогами.

## Возможности

- авторизация и регистрация пользователей
- сохранение чатов и истории сообщений
- гостевой режим без обязательного входа
- личный кабинет с редактированием профиля
- прикрепление файлов к сообщениям
- фокус-режим для более удобного чтения диалога
- аннотации и пометки для AI-ответов

## Технологии

- React
- Vite
- Django
- Django REST Framework
- SQLite

## Что потребуется

Для запуска проекта на компьютере должны быть установлены:

- Node.js 18 или выше
- Python 3.10 или выше

## Запуск проекта

```bash
npm install
npm run setup
npm run dev:all
```

После запуска откройте:

- frontend: `http://127.0.0.1:5173`
- backend: `http://127.0.0.1:8000`





## Отдельный запуск частей проекта

Если нужно запускать клиент и сервер раздельно, можно использовать отдельные команды.

Запуск frontend:

```bash
npm run dev
```

Запуск backend:

```bash
npm run dev:server
```

## Полезные команды

Сборка клиентской части:

```bash
npm run build
```

Проверка backend-тестов:

```bash
npm run test:backend
```

## Структура проекта

- `src/` — клиентская часть приложения
- `server/` — серверная часть на Django
- `scripts/setup.mjs` — скрипт для первичной подготовки backend
- `scripts/run-backend.mjs` — скрипт запуска Django-сервера




## Возможные проблемы при запуске

### Python не найден

Проверьте, установлен ли Python:

```bash
python3 --version
```

На Windows можно проверить так:

```bash
py -3 --version
```

### Не запускается backend

Если сервер не стартует, заново выполните подготовку:

```bash
npm run setup
```

### Не работает авторизация или чаты

В этом случае сначала убедитесь, что backend действительно запущен и доступен по адресу:

```text
http://127.0.0.1:8000
```
