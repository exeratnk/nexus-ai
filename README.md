# NexusAi

NexusAi — AI-чат с удобным интерфейсом, личным кабинетом, фокус-режимом, аннотациями сообщений и гибкой системой хранения диалогов для гостей и пользователей.

## Что умеет проект

- Мультичат: создание, удаление, переименование, якоря по сообщениям.
- Режимы ответа и выбор модели в каждом чате.
- Отправка сообщений с вложениями.
- Авторизация и регистрация по токенам.
- Личный кабинет: редактирование профиля, изменение аватара и информации о себе.
- Фокус-режим: скрытие лишнего интерфейса для чтения и работы только с диалогом.
- Аннотации AI-сообщений:
  - метки `Важно`, `Сохранить`, `Перепроверить`,
  - заметки к сообщениям,
  - отдельный дайджест аннотаций с фильтрами.

## Плюсы

- Быстрый запуск одной командой.
- Понятный UI без лишних действий.
- Гостевой режим работает без обязательной регистрации.
- Чаты зарегистрированных пользователей хранятся на сервере.
- Новички не теряют гостевые чаты после регистрации.

## Как работает сохранение чатов

- В гостевом режиме чаты сохраняются локально в браузере.
- При регистрации гостевые чаты переносятся в новый аккаунт.
- При входе в существующий аккаунт гостевые чаты не переносятся.
- Для авторизованных пользователей чаты сохраняются на сервере.

## Требования

- Node.js 18+
- Python 3.10+

## Установка (один раз)

```bash
git clone https://github.com/exeratnk/nexus-ai.git
cd nexus-ai/chatai
npm install
cd server
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
cd ..
```

## Правильный запуск (рекомендуется)

Перед запуском активируй виртуальное окружение сервера:

```bash
cd nexus-ai/chatai
source server/.venv/bin/activate
npm run dev:all
```

Команда `npm run dev:all` запускает:
- фронтенд на `http://localhost:5173`
- сервер на `http://localhost:8000`

## Альтернативный запуск (в 2 терминалах)

Терминал 1:
```bash
cd nexus-ai/chatai
source server/.venv/bin/activate
npm run dev:server
```

Терминал 2:
```bash
cd nexus-ai/chatai
npm run dev
```

## Полезные команды

```bash
npm run dev        # только фронтенд
npm run dev:server # только сервер
npm run dev:all    # фронтенд + сервер вместе
npm run build      # production-сборка фронтенда
npm run preview    # предпросмотр production-сборки
```

## API

Базовый префикс: `http://localhost:8000/api/auth/`

Основные маршруты:
- `register/`
- `login/`
- `refresh/`
- `logout/`
- `profile/`
- `chats/`

## Структура проекта

- `src/` — клиентская часть.
- `src/hooks/useAuth.js` — авторизация/регистрация/профиль.
- `src/hooks/useChats.js` — чаты, сообщения, хранение гостевых/серверных данных.
- `src/components/ProfileModal.jsx` — личный кабинет.
- `src/components/AnnotationDigest.jsx` — дайджест аннотаций.
- `server/` — серверная часть и модели данных.
